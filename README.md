# كلمات دراكون السرية: دليل التشغيل

لعبة «كلمات سرية» أونلاين بدون حساب للاعبين. تحتاج مرة وحدة تسوي ثلاث أشياء مجانية: مشروع Firebase، استضافة على GitHub Pages، وتثبيت على الموبايل.

الخدمتان مجانيتان وما تطلبان بطاقة بنكية. الباقة المجانية في Firebase تكفيك أنت وأصدقائك بسهولة.

## محتويات المجلد

| الملف | وظيفته |
|---|---|
| `index.html` | اللعبة نفسها |
| `firebase-config.js` | هنا تلصق إعدادات Firebase (الخطوة 5) |
| `firestore.rules` | قواعد الحماية (الخطوة 4) |
| `manifest.webmanifest`، `sw.js`، `icon-*.png` | تخلّي الموقع يتثبت كتطبيق |

## الخطوة 1: مشروع Firebase

1. افتح <https://console.firebase.google.com> وسجّل بحساب Google.
2. اضغط **Add project** (إضافة مشروع) واكتب أي اسم، مثل `kalimat`.
3. عطّل Google Analytics (ما تحتاجه) واضغط **Create project**.

## الخطوة 2: تفعيل الدخول المجهول

1. من القائمة: **Build** ثم **Authentication** ثم **Get started**.
2. تبويب **Sign-in method** ثم اختر **Anonymous**.
3. فعّله واضغط **Save**.

هذا الي يخلي اللاعب يدخل بدون تسجيل.

## الخطوة 3: قاعدة البيانات

1. **Build** ثم **Firestore Database** ثم **Create database**.
2. اختر أقرب منطقة لكم (مثلاً `europe-west`) ثم **Production mode** ثم **Create**.

## الخطوة 4: قواعد الحماية

1. في Firestore افتح تبويب **Rules**.
2. امسح الموجود والصق محتوى ملف `firestore.rules` كله.
3. اضغط **Publish**.

## الخطوة 5: ربط اللعبة بمشروعك

1. اضغط أيقونة الترس ثم **Project settings**.
2. انزل إلى **Your apps** واضغط أيقونة الويب `</>`.
3. اكتب أي اسم واضغط **Register app** (لا تفعّل Hosting).
4. راح يظهر لك كود فيه `firebaseConfig`. انسخ القيم: `apiKey` و`authDomain` و`projectId` و`appId`.
5. افتح ملف `firebase-config.js` والصق القيم مكان كلمات `PASTE`.

## الخطوة 6: رفع اللعبة على GitHub Pages

1. سجّل في <https://github.com> (مجاني).
2. اضغط **New repository**، سمّه مثلاً `kalimat`، واجعله **Public**، ثم **Create**.
3. اضغط **uploading an existing file** وارفع **كل** الملفات الي في المجلد (بعد فك الضغط)، ثم **Commit changes**.
4. افتح **Settings** ثم **Pages**. اختر Branch: `main` وFolder: `/ (root)` ثم **Save**.
5. بعد دقيقة أو دقيقتين يظهر الرابط، شكله: `https://اسمك.github.io/kalimat/`

## الخطوة 7: السماح بدومين موقعك في Firebase

1. في Firebase: **Authentication** ثم **Settings** ثم **Authorized domains**.
2. اضغط **Add domain** واكتب `اسمك.github.io` (بدون `https` وبدون اسم المستودع).

## الخطوة 8: التثبيت على الموبايل

افتح رابط الموقع في Chrome ثم قائمة النقاط الثلاث ثم **Install app** أو **Add to Home screen**. تظهر لك أيقونة اللعبة وتفتح بشاشة كاملة.

## اللعب

1. أنشئ غرفة، ثم اضغط **مشاركة الدعوة** وأرسل الرابط للأصدقاء على واتساب أو تلغرام.
2. كل واحد يفتح الرابط، يكتب اسمه، ويدخل الغرفة مباشرة.
3. اختاروا الفرق والأدوار وابدؤوا.
4. للتجربة لوحدك: زر **تجربة لوحدي** في الردهة.

## تنظيف الغرف القديمة (اختياري)

كل غرفة ولاعب فيها حقل `expireAt` يساوي 48 ساعة من آخر نشاط. لتحذف Firebase القديم تلقائياً:

1. Firestore ثم **Indexes** ثم تبويب **TTL** (أو Time-to-live) ثم **Create policy**.
2. أنشئ سياسة لـ Collection group اسمها `games` والحقل `expireAt`، وأخرى لـ `players` والحقل `expireAt`.

إذا تخطيتها ما يصير شي، الغرف القديمة تبقى بس وما تضر.

## ميزات اللعبة

- **تيم الصياد**: ثيم خاص كل كلماته تنزل باللوحة كاملة (9 كلمات)، والباقي من الأنواع الثانية. لتغيير الأسماء، عدّل السطر `id: "hunter"` داخل `index.html`.
- **ثيمات خاصة**: رمضان والعيد، كرة القدم، الأعراس، مدن عراقية، سوشيال ميديا، ومهن. تتفعّل من الردهة، وتكون مطفأة افتراضياً.
- **ألقاب آخر الجولة**: ملك البيض، هدية الخصم، الخبير، سوّد وجهه، والقائد النايم (إذا شغّلتم المؤقت).
- **الأدوار تنقفل أثناء الجولة**: قائد واحد لكل فريق يتحدد لحظة البدء، ولا أحد يكدر يبدّل دوره ليشوف الألوان. التبديل يرجع بعد انتهاء الجولة.
- **أنواع الكلمات والصعوبة والمؤقت وتدوير القائد**: يضبطها المضيف في الردهة.
- **قلب البطاقة مع رسالة**: «عاشت ايدك» لكلمة فريقك، «ثول» للبيضة، «طاح حظك» لكلمة الخصم، «سوّد الله وجهك» للقاتل.
- **نقاط**: عداد الفوز يستمر بين الجولات.
- **تنبيه الدور**: اهتزاز وصوت عند دور فريقك، وزر لإيقافه.
- **إخراج لاعب**: زر «إخراج» بجانب اسمه للمضيف فقط.

## إذا طلعت مشكلة

- **«لم يتم ربط Firebase بعد»**: لم تلصق الإعدادات في `firebase-config.js`، أو الملف ما انرفع.
- **«تعذّر الاتصال بالخدمة»**: تأكد أن الدخول المجهول مفعّل (الخطوة 2) وأن الدومين مضاف (الخطوة 7).
- **«رُفض الطلب»**: قواعد Firestore ما انتشرت. كرر الخطوة 4 واضغط Publish.

## تحديث اللعبة لاحقاً

عدّل الملف على GitHub (أيقونة القلم) أو ارفع نسخة جديدة منه واضغط **Commit**. التحديث يظهر للاعبين خلال دقيقة تقريباً بدون أي إعداد إضافي.

## ملاحظة أمان

ألوان الكلمات محفوظة في قاعدة البيانات، فمن يفتح أدوات المطور بالمتصفح يكدر يشوفها. هذا مناسب للعب مع الأصدقاء، بس مو مناسب لمسابقات جدية.
